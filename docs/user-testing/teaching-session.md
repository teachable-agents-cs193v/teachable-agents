# Teaching session walkthrough notes

Betania's notes from a user interview on a teaching session with Pip.

During user testing, the student I interviewed mentioned that the formatting of the text for Pip could be improved, especially for math and code. For example, math should be displayed using actual mathematical notation instead of writing things like "x times x," and code should appear in code blocks instead of regular text. Also, the user mentioned that important information with highlighted more and colors should be stronger for readability. Another issue I noticed was that Pip ends teaching sessions too quickly, even when the student hasn't fully explained the concept or demonstrated understanding. Also, when the user gave Pip spelling mistakes, it didn't always understand what the student was trying to say. Looking at the student's explanations, Pip could also be more critical of the student's responses and ending the session too early.
